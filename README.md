# 🎂 Interactive Birthday Greeting Web Card

A responsive and interactive web-based birthday greeting card built with pure HTML, CSS, and JavaScript. Designed to deliver a personalized digital celebration experience with smooth animations and interactive elements.

## ✨ Features
* **Custom Animations:** Smooth CSS transitions and keyframe animations including a rotating 3D birthday cake with flickering candle flame, fireworks, floating photo & text bubbles, and emoji rain.
* **Interactive Elements:** Welcome screen, Locket-style photo gallery with modal slider & auto-play, interactive birthday wish chat, memory calendar, built-in music player, and double-tap-to-cut 3D cake.
* **Responsive Design:** Optimized for both desktop and mobile screens so recipients can view it easily via shared links.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Deployment:** Vercel / GitHub Pages

## 🚀 How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/Twinklee001/locket.git
   ```
2. Open the project folder and serve it with a local static server (e.g. VS Code Live Server or `npx serve`) or deploy it directly to Vercel / GitHub Pages, then open `index.html` in your browser.
